# A 股分析 · 推荐 / 策略 / 大师共识

单文件深色主题 Web UI（Flask + pandas，行情走腾讯/新浪/东财多源），提供个股技术分析、自选股管理、持仓管理、每日买卖策略、「今日推荐」，并把 8 套投资大师方法论直接嵌在搜索/自选/持仓三处。

## 功能

| 页面 | 内容 |
| --- | --- |
| 首页 | **今日推荐**（稳健 3 只 + 激进 3 只，基于最近一个交易日收盘数据；每只可展开「为什么」看逐条打分）+ **自选股今日策略**（每只给出 买入/加仓/持有/减仓/止损/观望 与关键价位）+ **筛选逻辑** 面板（把候选池、过滤条件、打分项摊开写清） |
| 自选 | 单只添加（代码 / 中文名 / 拼音，覆盖沪深 A 股、北交所、ETF、港股）、多行批量导入、删除、直接设置持仓；每只的今日策略下面带一行**大师共识**（N/8 位认可）与 8 个方法论契合度小标签 |
| 持仓 | **账户总资金 + 持仓全景 + 组合建议 + 明日预案 + 实时盯盘**：每只票的股数/成本/浮盈、占总资产比例、目标权重与「该买/卖多少股」（含**佣金/印花税/过户费**后的实付与到手）、明日偏多/偏空判断与条件式预案；组合层面看仓位、现金、集中度、亏损面；打开「实时盯盘」后每 60 秒用最新报价对照止损/目标/MA20，到点弹浏览器通知；每只持仓也带一行**大师共识** |

| 搜索 | 任意个股的短线（1–2 周）/长线（3–12 月）评分、关键价位（止损/加仓/止盈）与分项指标；下方接**大师视角**：8 套方法论（巴菲特/格雷厄姆/林奇/欧奈尔/利弗莫尔/索罗斯/西蒙斯/邓普顿）各打一次分，每条标准给出「过没过 + 实际数值」，附共识统计 |

## 运行

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements_web.txt   # Windows
# source .venv/bin/activate && pip install -r requirements_web.txt   # Linux/Render

set PORT=5000 && .venv\Scripts\python web_app.py    # Windows
# PORT=5000 python web_app.py                        # Linux
```

或生产模式：`gunicorn web_app:app --bind 0.0.0.0:$PORT --workers 2 --timeout 120`（即 `start.sh`）。

## 数据保存位置

所有用户数据都写在**项目目录内的 `data/`**（每次保存前自动在 `data/backups/` 留一份快照，最多 50 份，可在持仓页「快照」里一键回滚）（可用环境变量 `STOCK_DATA_DIR` 改到别处）：

- `data/portfolio.json` —— 自选股、持仓与账户总资金（`{"capital": 200000.0, "stocks": {"600519": {"name": "贵州茅台", "added": "...", "position": {"shares": 100, "cost": 1380.0}}}}`；`capital = 0` 表示还没设总资金）
- `data/recommend.json` —— 当日推荐缓存（含 `for_date` 与 `data_date`，当天只算一次）

> ⚠️ **Render 免费实例的文件系统是临时的**：重新部署或实例重启会清空 `data/`，自选股会丢。要长期保存自选，请挂载持久磁盘（Render Disk → 挂到 `/data`）并设置环境变量 `STOCK_DATA_DIR=/data`，或用 `start.sh` 之外的方式把 `data/` 指向持久卷。

## 数据源

行情不依赖单一接口：单只 250 日线在 baostock 上要 2–7 秒，而且**只有沪深 A 股**（北交所、ETF、港股一律查不到）。现在按下面的顺序自动降级，任何一源失败都不影响使用：

| 用途 | 首选 | 兜底 1 | 兜底 2 | 兜底 3 |
| --- | --- | --- | --- | --- |
| 代码/名称 → 股票 | 新浪 suggest | 东财 suggest | baostock | — |
| 日线 | 东财（真实成交额，全市场） | 腾讯（估算成交额） | 新浪（补北交所） | baostock（仅沪深 A 股） |
| 最新价 | 腾讯 | 东财 | baostock | — |

- **覆盖面**：沪深 A 股、北交所（`43/83/87/92` 开头，老代码会被新浪自动换成新号，如 `832566 → 920566`）、场内 ETF/LOF（`510300`、`159915`）、港股（`00700` 这类 5 位代码）。
- **健康检查**：某源连续失败会被标记 5 分钟不再优先使用（`fetcher.source_status()` 可查）；「这只票在这个源没有数据」不会连坐整个源。
- **日线缓存**：`data/cache/kline/` 落盘缓存 30 分钟（`fetcher.CACHE_TTL`），命中约 0.01 秒。推荐/策略/持仓/大师会反复要同一只票的日线，不缓存会被上游按 IP 限流。
- **腾讯接口**：老的 `web.ifzq.gtimg.cn` 会按 IP 返回 501，主用 `proxy.finance.qq.com/ifzqgtimg/appstock/app/newfqkline/get`（对北交所也给满 250 根），老接口只作兜底。
- **代码规范化**：统一走 `codes.norm_code()`，港股保持 5 位（**不能**补成 6 位，否则 `00700` 会变成 A 股 `000700`）。
- **港股注意**：港币价格按人民币口径参与仓位计算（不换算汇率），跨市场持仓的比例会略有偏差。

## 关键实现

- `fetcher.py` —— 多源降级入口：`resolve_stock_code`（新浪→东财→baostock，带 `_plausible` 校验，避免 `zzzz` 被联想成不相干的指数）、`fetch_daily_kline`（东财→腾讯→新浪→baostock，某源只给几根 K 线就继续试下一个）、`get_stock_info`、`latest_trading_date`；`FetchError` 表示「接口暂时不可用」，与「查无此股」严格区分
- `em.py` / `tq.py` / `sina.py` —— 东财、腾讯、新浪三个数据源的最小封装（各自带 `*Error` 与 `*NetworkError`）
- `codes.py` —— 股票代码规范化（A 股 6 位、港股 5 位、去市场前缀）
- `indicators.py` —— MA / MACD / KDJ / RSI / BOLL / ATR / ADX / 支撑压力
- `analyzer.py` —— 短线 7 项、长线 6 项加权打分
- `positions.py` —— 止损位、加仓位、止盈位
- `strategy.py` —— 结合均线结构、量价、RSI、20 日高低点与持仓盈亏，输出当日操作建议与理由
- `fees.py` —— A 股/ETF/港股的费用估算：佣金万 2.5（最低 5 元）、印花税卖出 0.05%（ETF 免）、过户费 0.001%、港股印花税 0.1% + 结算费；买卖都给出「实付 / 到手」
- `tomorrow.py` —— 明日预案：用今天收盘的均线结构、收盘位置、量比、RSI、20 日高低点算偏多/偏空与置信度，给出明日支撑/阻力、回踩买区与条件式操作（「冲高到 X 不追，跌破 Y 减一半」）；低价品种（ETF）自动用三位小数
- `plan.py` —— 账户级交易计划：把「个股动作 + 持仓股数 + 总资金」换算成可下单的数量（买入按整手、卖出可到零股、单票上限 25%、现金下限 10%），金额保留两位小数并扣掉手续费；并给组合级提示（仓位/现金/集中度/亏损面）。**总资金的正确填法是「可用现金 + 持仓成本」**：填得比持仓成本还小时，现金按 0 计并给出红色提示，不会把总资产算成负数
- `recommend.py` —— 84 只主流标的的固定股票池（全市场逐只拉取过慢），打分后分「稳健 / 激进」各取 3 只；过滤 ST、退市、成交清淡、涨停、追高（单日 >5%）、RSI > 80、短线评分 ≤ -1 的标的；**每个打分项都记录「过没过 + 实际数值」（`factors`）**，前端「为什么」直接摊开；规则文案集中在 `LOGIC`；推荐在后台线程计算并按自然日缓存
- `snapshot.py` —— 把日线压成一行快照指标（均线位置/斜率、涨幅、波动、量比、年内高低点、布林位置等），推荐与大师分析共用同一套口径
- `masters.py` —— 8 套公开方法论的技术面近似版，每套 6 条加权标准；权重和为 10，得分/满分 = 契合度；核心两条全过且契合度 ≥ 55% 才算「值得关注」
- `portfolio.py` —— 自选与持仓的原子写入（tmp + `os.replace`）

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/recommend` | 今日推荐；`?force=1` 重算；`status=done/running/error`，附带 `logic` 规则说明 |
| GET | `/api/strategy` | 自选股今日策略（每只附 `masters` 精简版：8 套契合度 + 共识） |
| GET | `/api/masters?query=600519` | 大师方法论分析（接受代码或中文名，单只约 1 秒）；页面已不单开入口，`/api/analyze` 的 `masters` 字段用的是同一份逻辑 |
| POST | `/api/analyze` | 单只短线/长线分析、关键价位，以及完整 `masters`（含每条标准） |
| GET/POST | `/api/watchlist` | 自选列表 / 添加（`{code}` 或 `{text}` 批量） |
| DELETE | `/api/watchlist/<code>` | 删除自选 |
| POST | `/api/position` | 直接建仓 `{query, shares, cost}`（代码或名称，自动补进自选） |
| PUT | `/api/position/<code>` | 设置持仓 `{shares, cost}`；`shares=0` 即清仓（负数/只填股数不填成本会 400） |
| GET/PUT | `/api/account` | 读 / 设账户总资金 `{capital}` |
| GET/POST | `/api/backups` | 列持仓快照 / 回滚到某一份 `{name}` |
| GET | `/api/portfolio` | 持仓全景 + 组合建议 + 明日预案（价格用实时报价，指标用 30 分钟日线缓存） |
| GET | `/api/alerts` | 实时盯盘信号：现价对照止损/加仓/止盈/MA20，返回 `danger/warn/action/info` 四档；前端每 60 秒轮询 |

## 实时盯盘（到点通知）

持仓页顶部有开关，状态存在浏览器 `localStorage`（`stockWatchOn`），关闭页面不丢：

1. 打开后立刻检查一次，之后每 60 秒请求 `/api/alerts`；
2. 触发的信号按 `danger → warn → action → info` 排序显示在页面顶部横幅；
3. 同时用浏览器 Notification 弹系统通知（首次会请求授权；被拒绝就只显示横幅）；
4. **同一个信号 10 分钟内不重复弹**（`ALERT_COOL`），避免每轮刷屏。

信号口径：`stop`（跌破止损）、`near_stop`（离止损 1.5% 内）、`target`（到目标价）、`add`（未持仓回到加仓位且建议买入）、`ma20`（跌破 MA20）、`surge`（当日涨跌 ±5%）。注意这是**浏览器里开着页面**才有效；关掉页面就不会再报。
